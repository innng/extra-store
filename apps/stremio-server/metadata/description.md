## Stremio Server

Stremio Server provides the streaming backend for Web Stremio. It stores its
working data locally and can be reached through your Runtipi application domain
or the assigned LAN port.

Browser playback depends on the stream's codecs. H.264/AVC video with
browser-supported audio is the most compatible choice; HEVC, DTS, and some MKV
sources may still require the Stremio desktop client.
